\section{Switching Event Separation}
In power electronics analysis, it is standard practice to evaluate four distinct switching transients separately: active-on (device turn-on), active-off (device turn-off), passive-on (body-diode turn-on), and passive-off (body-diode turn-off)~\cite{fritz_toward_2020}. Here, the active device initiates the transient while the passive device (conducting body diode) is turned off during commutation.

For EMC analysis, this separation is particularly valuable: it identifies which switching event dominates in each frequency band, enabling targeted understanding of noise generation mechanisms. 
Direct measurement at the semiconductor ports enables this separation, a key advantage unavailable in conventional system level EMC measurements, which capture only the aggregated noise from all events.

To achieve event-resolved separation in the frequency domain, the snap-and-mirror method is applied~\cite{kragl_impact_2024}, whose operating principle is shown in \fref{fig:SnapNMirror}. 
The procedure works by mirroring the measured signal around each switching cycle midpoint, producing four synthetic signals (one per event type), which can then be analyzed separately.

This function identifies the midpoints of each switching cycle \mi{t}{m,n} and mirrors the signal around this axis, which can be formulated as

\begin{equation}
	s_\mathrm{new}(t) = 
	\begin{cases}
		s(t) 					 		& \text{, for } \mi{t}{m,n}~~~< t < \mi{t}{m,n+1} \\
		s(-t + 2\cdot\mi{t}{m,n+1}) 	& \text{, for } \mi{t}{m,n+1} < t < \mi{t}{m,n+2} \\
		s(t) 					 		& \text{, for } \mi{t}{m,n+2} < t < \mi{t}{m,n+3} \\
		s(-t + 2\cdot\mi{t}{m,n+3}) 	& \text{, for } \mi{t}{m,n+3} < t < \mi{t}{m,n+4} \\
		\cdots
	\end{cases}
	\label{eq:snap}
\end{equation}

This transformation is valid for amplitude-spectrum analysis because time mirroring and shifting affect only the phase of the Fourier transform, not its magnitude. Specifically:

\begin{equation}
	\mathcal{F}\{s(-t)\} = S(-f) = S^\ast(f)
\end{equation}

\begin{equation}
	\mathcal{F}\{s(t-\mi{t}{0})\} = S(f)e^{-j\omega \mi{t}{0}}
\end{equation}

Therefore, the amplitude spectrum $|S(f)|$ remains unchanged. 

This method performs best when the spectrum is evaluated with a peak detector in post-processing.
If a normal FFT or an average detector is used, the spectral content is increased by a factor of up to 2, because the mirrored signal adds to the original signal.
